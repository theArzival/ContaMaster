# 📊 ContaMaster — Estudio Contable Profesional

Landing page profesional desarrollada como proyecto académico en el curso **Hojas de Estilo en Cascada Avanzado (UTP, Ciclo 2026-1)**.  
El sitio web representa un **estudio contable moderno**, aplicando de manera integral técnicas avanzadas de **CSS, JavaScript y arquitectura modular**.

---

## 🚀 Características del Proyecto
- **Página principal (index.html)** con:
  - Hero con animaciones
  - Estadísticas dinámicas
  - 6 servicios destacados
  - Sección "Nosotros"
  - Proceso en 4 pasos
  - Diferenciadores competitivos
  - Planes de precios
  - Testimonios
  - Formulario de contacto

- **6 páginas de servicio individuales**:
  - Contabilidad General
  - Tributación & SUNAT
  - Planillas & RRHH
  - Auditoría Financiera
  - Análisis Financiero
  - Asesoría Empresarial

- **Arquitectura CSS modular**:
  - `main.css` → variables, tipografía y utilidades
  - `components.css` → componentes principales
  - `extra.css` → secciones adicionales

- **JavaScript interactivo (`app.js`)**:
  - Navbar responsivo
  - Menú hamburguesa
  - Animaciones con scroll
  - Contadores dinámicos
  - Tabs y ticker animado
  - Validación de formularios

---

## 🛠️ Tecnologías Utilizadas
- **HTML5**
- **CSS Avanzado** (Grid, Flexbox, Variables, Animaciones)
- **JavaScript (ES6+)**
- **Preprocesadores conceptuales** (SASS/LESS equivalentes)
- **Principios de frameworks**: Bootstrap, Tailwind, Material Design, Materialize (aplicados manualmente)

## 🎨 Técnicas CSS Avanzadas
- **Responsividad total** con media queries en 3 breakpoints (600px, 900px, 1100px).
- **Animaciones personalizadas** con `@keyframes` (fadeUp, shimmer, float, pulse).
- **Transiciones suaves** en navbar, cards, botones y dropdowns.
- **IntersectionObserver API** para reveals al hacer scroll.
- **Glassmorphism** con `backdrop-filter`.
- **Design tokens**: paleta de colores, tipografía, espaciado y sombras reutilizables.
